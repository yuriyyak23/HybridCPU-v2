# Repository Layout and Code Map

## Goal of this chapter

This chapter maps the current repository layout to implementation owners,
compatibility seams and validation evidence. It does not appoint architecture
authority. Architecture authority is the Markdown paper under
[`ResearchPaper/section/md base/`](<../../../ResearchPaper/section/md base/>).
ArchitectureAuthorityRefactor records the current roadmap, decisions and proof context; this WhiteBook is
system context and must be checked against both the paper and live source.

## Top-level live layout

The top-level roots relevant to this map are:

- [`ResearchPaper/`](../../../ResearchPaper/) for architecture authority;
- [`Documentation/Documentation/`](../) for the moved WhiteBook context;
- [`Documentation/ArchitectureAuthorityRefactor/`](../../ArchitectureAuthorityRefactor/) for current ArchitectureAuthorityRefactor status, governance and
  evidence links;
- [`HybridCPU_ISE/`](../../../HybridCPU_ISE/) for runtime implementation and
  retained compatibility source;
- [`HybridCPU_Compiler/`](../../../HybridCPU_Compiler/) and
  [`CpuInterfaceBridge/`](../../../CpuInterfaceBridge/) for producer/bridge
  integration;
- [`HybridCPU_ISE.Tests/`](../../../HybridCPU_ISE.Tests/) and
  [`TestAssemblerConsoleApps/`](../../../TestAssemblerConsoleApps/) for
  executable evidence and diagnostic consumers;
- [`eng/validate.ps1`](../../../eng/validate.ps1) for the canonical validation
  command surface.

These roots have different roles. The paper owns architecture claims; code owns
implemented behavior at its named boundary; tests and ArchitectureAuthorityRefactor artifacts provide
evidence; WhiteBooks provide cross-system context.

## Runtime code map

Current implementation owners are distributed rather than rooted in the old
`HybridCPU_ISE/Core/` map:

- declared static ISA rows remain in
  [`NonRTL/Arch/OpcodeInfo.Registry.Data.cs`](../../../HybridCPU_ISE/NonRTL/Arch/OpcodeInfo.Registry.Data.cs)
  and its family partials; the committed generated projection is
  [`GeneratedIsaShadowCatalog.g.cs`](../../../HybridCPU_ISE/NonRTL/Arch/Generated/GeneratedIsaShadowCatalog.g.cs).
  This is not a generated-source-only authority claim: handwritten registry
  input and generator read-back remain open RF-13 final-freeze work, as recorded
  by the [current RF-13 ledger](../../ArchitectureAuthorityRefactor/12_RF13/00_CURRENT_STATUS_AND_LEDGER.md).

  [`VliwDecoderV4.cs`](../../../HybridCPU_ISE/CloseToHSL/Core/Frontend/Decode/VliwDecoderV4Bridge/VliwDecoderV4.cs).
  The relocated
  [`DecodedBundleTransportProjector.cs`](../../../HybridCPU_ISE/Legacy/CloseToHSL/Core/Decoder/DecodedBundleTransportProjector.cs)
  remains a live canonical/fallback compatibility seam, not expired code.
- typed Stage A/Stage B admission, exact-slot compatibility, SMT/FSP nomination
  and lane materialization remain under
  [`CloseToHSL/Core/Pipeline/Scheduling/`](../../../HybridCPU_ISE/CloseToHSL/Core/Pipeline/Scheduling/),

  [`RetireCoordinator.cs`](../../../HybridCPU_ISE/CloseToHSL/Core/Architecture/Registers/Retire/RetireCoordinator.cs);

## Owner and evidence roles

| Surface | Role | Limitation |
|---|---|---|
| Paper Markdown | architecture authority | ArchitectureAuthorityRefactor, code, tests and WhiteBooks cannot silently widen it |
| Runtime/compiler source | implemented owner at the named boundary | file location or a `Legacy` name is not architecture or deletion authority |
| Tests, guards and validation artifacts | executable evidence | historical or excluded tests do not prove current reachability or removability |
| ArchitectureAuthorityRefactor current ledgers | implementation status and proof index | closed slice status does not replace paper authority or close all of RF-13 |
| WhiteBooks | system context and traceability | claims must remain bounded to paper, current source and named compatibility limitations |

## Current limitations

- The repository contains a mix of live code, historical docs, and experiment folders, which increases the chance of stale-path confusion.
- The current worktree includes a documentation relocation and broad source-tree
  refactoring; directory names are not stable architectural ABI.
- Generated-source-only static ISA authority and the full RF-13 final freeze are
  not complete claims in this chapter.
- Nine retained legacy-named source contours remain live under
  [`HybridCPU_ISE/Legacy/`](../../../HybridCPU_ISE/Legacy/); their RF-13 owner and
  caller dispositions are summarized by the
  [legacy completion audit](../../ArchitectureAuthorityRefactor/Evidence/RF13/rf13.12-legacy-consolidation-completion-audit.md).
